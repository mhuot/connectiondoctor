# control-kvm-switch (constructed from a real recording)

Shape taken from the Mac mini's real KVM flip at 22:19:06Z, which ships as the
dashboard's `kvm-mini`/`kvm-surface` fixtures.

One host cannot tell a KVM switch from a hub failure — the local evidence is
identical. That is the honest answer this fixture pins: an unattributed
incident, no critical finding, and the *fleet* view is where the migration
becomes visible because the same VID:PIDs appear on another host within
seconds. Any engine that calls this a fault from one host alone is guessing.
