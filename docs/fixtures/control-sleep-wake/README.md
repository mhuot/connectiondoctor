# control-sleep-wake (constructed)

Six devices vanish together at 03:00 and all six return together at 07:30.

This is the hardest control, because it looks *exactly* like grouped loss: same
instant, same shared parent. The distinguishing evidence is the symmetry —
everything that left came back, together, with no power deficit and no link
event in between. On Windows this is Modern Standby; on macOS it is sleep.
An engine that reports 'devices lost as a group' here is blaming the user's
night.
